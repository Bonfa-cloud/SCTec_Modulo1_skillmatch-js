# SkillMatch JS

## Objetivo do mini projeto
Simulador que compara as competências de um candidato com as exigências de vagas de Front-End Júnior, calcula a compatibilidade e recomenda o que estudar.

## Tecnologias
- JavaScript
- Node.js
- Visual Studio Code
- Git e GitHub

## Como executar
Com o Node.js instalado, abra o terminal na pasta do projeto e execute:

```bash
node teste.js
```

## Funcionalidades
- Calcula a porcentagem de compatibilidade.
- Classifica as vagas por compatibilidade.
- Identifica competências faltantes.
- Encontra a vaga com maior compatibilidade.
- Gera um plano de estudo priorizando competências exigidas por mais vagas.

## Conceitos utilizados
Variáveis, arrays, objetos, condicionais, laço `for`, funções, métodos de array, classes, herança, `this`, callback, closure, `Promise`, `async/await` e tratamento de erros.

## Cliente-servidor
O projeto simula localmente o carregamento de vagas com `Promise`, `setTimeout` e `async/await`. Não utiliza API nem precisa de internet para funcionar.

## Inteligência artificial
A IA foi utilizada como apoio para compreender conceitos, revisar o código, corrigir erros e organizar a documentação. O código foi testado localmente com Node.js.
